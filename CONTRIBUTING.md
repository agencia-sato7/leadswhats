# Fluxo de Commits (LEADSWHATS)

## Branch principal
- `main`

## Padrão de commits
- `feat(scope): ...` para nova funcionalidade
- `fix(scope): ...` para correção
- `chore(scope): ...` para manutenção
- `docs(scope): ...` para documentação

Exemplos:
- `feat(webhook): ingestão passiva whatsapp com classificação de origem`
- `feat(dashboard): métricas de vácuo 24h e tempo de resposta`
- `fix(frontend): reclassificação visível apenas para gestor/admin`

## Cadência sugerida
- 1 commit por bloco funcional fechado
- sempre validando endpoint/tela antes do commit
